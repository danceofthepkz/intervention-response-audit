Social simulation audit

When a cheaper model loses the response a simulation needs.

Suppose we want to study how a message spreads through a campus. We create a network of synthetic students. Whenever a student receives a message, a language model estimates how likely they are to share it. The simulation samples that decision; a reshare gives other students a chance to see the message.

Calling a language model for every decision is expensive. A cheaper model can learn to imitate its answers. But what happens if the cheaper model never receives the part of the message we want to study?

Our experiment asks a specific question: does changing how a message is framed still change the predicted response after we replace the language model?

Change the message, keep the situation.

We paused the simulation just before a student made a decision. We kept the student, their social connections, and their previous exposures fixed. Only the quoted message changed: one version cites an authority; the other expresses uncertainty.

Switch between the messages below. The original language model—our “teacher”—assigns a probability to resharing each one.

We repeated this test in 60 situations. Across them, the authority-framed messages increased the teacher’s mean reshare probability by 8.66 percentage points. The response was not uniform: some situations showed no change, or a change in the opposite direction.

Our baseline replacement, called R0, receives 27 numbers describing the student, message metadata, and exposure history. It does not receive the message text.

    
For the two messages above, all 27 numbers are identical. To this model, they are the same situation. Whatever it has learned, it must give both messages the same predicted probability.

  


  

  

    
This is not something that a better training algorithm can fix. Training can improve the shared answer, but it cannot make one input produce two different probabilities.

This explains what an average prediction score can miss. A model can improve its predictions overall without ever responding to the wording change. Predicting the average and preserving a response are different tasks.

    

      How we measure the error that remains
      
We use KL regret to compare the teacher’s probabilities with the shared answer. Lower is better. The curve below shows this error as the shared answer moves; the axes zoom around the current answer and the best compromise.

      

      
Current error:  nats. Minimum possible for this pair:  nats.

      
The best shared answer is the midpoint of the two teacher means. The error separates exactly into error above that midpoint prediction and an irreducible floor:

      
½ KL(pA ∥ q) + ½ KL(pH ∥ q)
= KL(m ∥ q) + JSD(pA, pH),
where m = (pA + pH) / 2.

      
The floor averages 0.01121 nats across the 60 pairs. It can be estimated from the teacher measurements before fitting a replacement. This plug-in estimate includes finite-call noise. For small differences at a fixed midpoint, the floor is proportional to the squared probability difference, so a meaningful signed response can have a modest KL penalty.

    


    
Give the missing information back.

    
We next trained three alternatives using the same data and fitting procedure. One receives a label identifying the framing. The others receive a numerical encoding of the message text, either in full or compressed.

    
Now the two messages can produce different inputs. Does the fitted model actually learn a different response? Choose an input below to see how much of the teacher’s mean response it recovered.

  


  

  

    
The text-aware alternatives recovered 81–87% of the mean response on these 60 situations. Giving the model the missing information made learning possible; it did not guarantee that learning would succeed everywhere.

    
On a separate check within these data—23 situations with wording absent from training—the alternatives did not improve response error over R0. These situations also had lower credibility and a smaller teacher response, so we cannot isolate the cause. Transfer to new wording was not demonstrated.

    
Before replacing a language model in a simulation, ask what changes the simulation must respond to. Test those changes while holding the situation fixed. If the proposed input hides a response that matters, no amount of fitting will recover it. If it preserves the distinction, learning and generalization still need to be tested.

  


  

    
Study details, data, and sources
      
This article accompanies When Aggregate Fidelity Misses Intervention Response: A Pre-Fitting Screen for LLM Social Simulation. The campus network contains 50 synthetic students. The confirmatory study used 60 frozen situations and three calls per message, or 360 calls. Including pilot and smoke tests, the audit used 564 calls and cost about $0.20.

      
The mean response was 8.66 percentage points; the state-bootstrap interval was 6.70–10.63 and the template-cluster interval was 5.93–11.48. The states were selected in a way that over-sampled long cascades. Message pairs also differ in length and wording, not only authority cues. The study measures responses to these template bundles, not human persuasion or effects on complete diffusion trajectories.
